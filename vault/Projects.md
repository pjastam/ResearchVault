# Projecten — mobiel

> Deze projecten leven in **git-repo's** (GitHub/Codeberg), niet in de vault.
> Op de Mac zijn het symlinks onder `authoring/projects/`; op iPad/iPhone open je ze via **Working Copy**.
>
> - ✏️ **Bewerken** → *Open in Working Copy* (clone eenmalig → edit → commit → push)
> - 🌐 **Snel lezen** → web-link (GitHub-app of Safari)
>
> 🔒 = private repo (vereist login/SSH-sleutel in Working Copy)
